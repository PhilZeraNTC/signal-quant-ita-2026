# Roadmap

## Phase 1: Data Ingestion

**Goal:** Establish reliable, lookahead-free market data and sentiment news ingestion using `yfinance`.
**Mode:** mvp
**Requirements:** INGEST-01, INGEST-02, INGEST-03, INGEST-04
**Success Criteria**:

1. System successfully fetches historical S&P 500 equity data and news via `yfinance` with exponential backoff.
2. Log returns and 21-day Realized Volatility are correctly calculated.
3. News is timestamped and execution data strictly separates t_close from t+1_open.

## Phase 2: Quant & Fundamental Agents

**Goal:** Build the predictive engines (LightGBM for volatility and Gemini for sentiment).
**Mode:** mvp
**Requirements:** QUANT-01, QUANT-02, QUANT-03, FUND-01, FUND-02, FUND-03
**Success Criteria**:

1. LightGBM agent predicts 21-day RV, tuned with Optuna and cross-validated with Purged Time-Series Split.
2. Fundamental agent deterministicly extracts sentiment [-1.0, 1.0] and rationales from financial text via Gemini API.

## Phase 3: Risk Allocation & Backtesting

**Goal:** Implement Volatility Targeting, Sentiment Tilt, Risk Bands, and the Point-in-Time Event-driven Backtester.
**Mode:** mvp
**Requirements:** RISK-01, RISK-02, RISK-03, BACK-01, BACK-02, BACK-03, BACK-04
**Success Criteria**:

1. Capital is allocated using inverse volatility and tilted by sentiment, capped at 1-2 adjustments/month via Risk Bands.
2. Backtester runs a t+1_open event-driven simulation factoring in transaction costs.
3. System outputs valid Sharpe Ratio and Max Drawdown metrics for the portfolio.
