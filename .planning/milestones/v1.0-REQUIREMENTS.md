# Requirements

## v1 Requirements

### Data Ingestion

- [x] **INGEST-01**: Fetch market data and news using `yfinance`.
- [x] **INGEST-02**: Calculate logarithmic returns and 21-day Realized Volatility.
- [x] **INGEST-03**: Enforce strict Lookahead Bias handling by separating t_close data from t+1_open execution.
- [x] **INGEST-04**: Implement Exponential Backoff for API rate limits.

### Quant Agent

- [x] **QUANT-01**: Predict future 21-day realized volatility using LightGBM.
- [x] **QUANT-02**: Tune LightGBM hyperparameters using Optuna.
- [x] **QUANT-03**: Perform cross-validation using Purged Time-Series Split (Gap TimeSeriesSplit).

### Fundamental Agent

- [x] **FUND-01**: Call Google AI Pro via Gemini API with Temperature 0.0 for deterministic JSON output.
- [x] **FUND-02**: Extract a continuous Sentiment Score between [-1.0, 1.0] from financial news.
- [x] **FUND-03**: Extract factual rationale directly from text to justify sentiment score and mitigate hallucination.

### Risk Agent

- [x] **RISK-01**: Allocate capital using Volatility Targeting (inverse volatility allocation).
- [x] **RISK-02**: Apply Sentiment Tilt (score * conviction factor) to base allocation.
- [x] **RISK-03**: Enforce Risk Bands to limit turnover to 1-2 adjustments per month.

### Backtester

- [x] **BACK-01**: Run an event-driven, Point-in-Time simulation.
- [x] **BACK-02**: Generate signals on t_close and execute on t+1_open.
- [x] **BACK-03**: Account for transaction costs (bps) in simulation.
- [x] **BACK-04**: Calculate and report Sharpe Ratio and Max Drawdown.

## v2 Requirements (Deferred)

(None defined)

## Out of Scope

- **Synchronous execution**: I/O bottlenecks must be avoided via strictly asynchronous architecture (`asyncio`).
- **Traditional technical indicators**: Focused purely on LightGBM volatility and Gemini sentiment.
- **Intra-day trading**: Execution is strictly t+1_open.
